# Boothku Online - Next.js Photobooth Studio

Clone lengkap dan standalone dari Boothku (Neo-brutalism photobooth studio online), siap deploy langsung ke Vercel!

## Fitur Utama
- **27 Template Lengkap**: Twin strip, Y2K digicam, aesthetic frame, vintage newspaper, spotify cover, dll.
- **Real-time Live Camera Viewfinder**: Countdown 3 detik, flash effect, rotate kamera depan/belakang.
- **Slot Positioning Engine**: Rendering otomatis foto ke koordinat persis setiap template via HTML5 Canvas.
- **Filter & Tone Adjustments**: Natural, Snow White, Korean Glow, Vintage 90s, Golden Hour, dll + sliders Brightness, Contrast, Saturation, Warmth, Vignette.
- **Export High-Res**: Download langsung file photostrip format PNG.

## Cara Deploy ke Vercel
1. Push folder proyek ini ke repository GitHub.
2. Buka dashboard [Vercel](https://vercel.com).
3. Import repository, lalu klik **Deploy**! (Framework Preset: Next.js).
